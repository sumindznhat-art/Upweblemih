# TOOL TÀI XỈU BAONAM

## 🚀 Deploy GitHub Pages
1. Tạo repo mới trên GitHub
2. Upload **toàn bộ** file giữ nguyên cấu trúc thư mục
3. Vào **Settings → Pages → Source: main / root → Save**
4. Truy cập `https://<user>.github.io/<repo>/`
